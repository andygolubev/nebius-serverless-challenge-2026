# Bring Your Robot sample MJCF files

These two original Sim2Policy examples are intentionally small, self-contained, and built only
from MuJoCo primitive geometry. `sample-quadruped.xml` models a simple eight-actuator four-legged
robot; `sample-biped.xml` models a seven-actuator two-legged robot. They contain no meshes,
textures, plugins, includes, external paths, generated media, or third-party model geometry.

Download either file from **My Robots**, keep the declared type shown beside it, and upload the
unchanged XML to exercise the same public validator used for every tenant robot. The beta validates
structure and lets you compose a bounded setup; it does not yet train uploaded models.
