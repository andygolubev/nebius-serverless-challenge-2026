# Sample deliverables

These files are sanitized, lightweight examples for readers and judges. They are not raw run
artifacts and do not contain checkpoints, TensorBoard logs, credentials, account IDs, bucket names,
or full videos.

- `sample-metrics.json`: representative Track B metrics document with unavailable optional values
  shown explicitly.
- `sample-summary.md`: matching human-readable report excerpt.
- `sample-reward-curve.png`: generated reward curve preview.
- `teaser.gif`: tiny illustrative progression teaser, intentionally small enough for Git.

Full reproducible outputs should live in object storage under a run-specific prefix.
